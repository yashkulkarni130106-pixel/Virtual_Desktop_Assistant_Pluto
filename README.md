🚀 Pluto – Virtual Desktop Assistant (VDA)

Pluto is an AI-powered Virtual Desktop Assistant (VDA) that enables users to interact with their computer using voice and text commands. It is designed to automate everyday desktop tasks, improve productivity, and provide a natural human-computer interaction experience.

Built with Python and the Eel framework, Pluto combines the power of web technologies (HTML, CSS, and JavaScript) with Python's automation capabilities to create a modern desktop application with an interactive user interface.

✨ Features
🎤 Voice command recognition
💬 Interactive chat-based interface
🔊 Text-to-Speech (TTS) responses
📂 Open desktop applications (Notepad, Calculator, VS Code, Chrome, etc.)
🌐 Perform web searches
📝 Voice-to-text typing in desktop applications
⚡ Desktop automation and system control
📁 Open folders and files
🎨 Modern web-based UI powered by Eel

📌 Project Objective
The goal of Pluto is to simplify daily computer interactions by allowing users to perform tasks through natural voice and text commands. It bridges the gap between traditional desktop applications and intelligent AI assistants by combining speech recognition, desktop automation, and a user-friendly interface.

🚀 How It Works
The user gives a voice or text command.
Pluto processes the command using Python.
The assistant identifies the requested action.
The corresponding automation task is executed.
Pluto provides voice and visual feedback to the user.
